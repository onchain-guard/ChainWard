- 값 = `비율 [95% 신뢰구간] · 적중/실행`. 0/N 은 "0%"가 아니라 "상한 이하"로 읽는다.

- (부분) = ✅ 이지만 반복 중 일부만 성공했다. 해석할 때 감안한다.
- passthrough 는 툴 호출이 필요 없는 지표라 대조군과 무관하게 남긴다.
